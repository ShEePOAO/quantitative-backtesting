# Quant Studio 使用手冊

Quant Studio 是一個**量化回測**：在瀏覽器裡用 Python 寫交易策略、設定回測成本、執行回測，然後讀取績效、權益曲線、買賣點與交易明細。支援多資產等權／加權組合回測。

> 本工作台只包含「自訂策略」這一頁的功能，是原本量化回測軟體的獨立重寫版。

---

## 1. 快速開始

1. 啟動後端：在專案目錄執行 `python server.py`（預設 `http://127.0.0.1:8050`）。
2. 用瀏覽器打開 `http://127.0.0.1:8050`。
3. 左側「策略程式碼」已載入範本（EMA 快慢線交叉）。直接按右上角**執行回測**即可看到結果。
4. 想改策略：編輯左側程式碼 → 按**執行回測**。

## 2. 資料來源與資產

| 項目 | 說明 |
|------|------|
| 本地 CSV | 讀取原軟體的 `data\import_csv`（唯讀共用），加密貨幣為 1 分鐘 K 線聚合 |

## 3. 自訂策略契約

程式碼需定義 `generate`，回傳**目標倉位序列**：

```python
import pandas as pd
import numpy as np

PARAM_DEFS = {
    "fast": {"label": "快線週期", "type": "int", "min": 2, "max": 200, "default": 20, "step": 1},
    "slow": {"label": "慢線週期", "type": "int", "min": 5, "max": 400, "default": 60, "step": 1},
}

def generate(df, params):
    fast = df["close"].ewm(span=params["fast"], adjust=False).mean()
    slow = df["close"].ewm(span=params["slow"], adjust=False).mean()
    return (fast > slow).astype(int)
```

- 函式簽名可為 `generate(df, params)` 或 `generate(df)`。
- 回傳值意義：**0 = 空倉、1 = 做多、-1 = 做空**。
- `df` 欄位為 `open / high / low / close / volume`，索引為時間（DatetimeIndex）。
- 已預載於命名空間：`pd`、`np` 與多種技術指標（見 §5.1）。
- **調參自動出現**：程式碼用到哪個指標（例如 `rsi(df["close"], 14)`、`macd(df["close"])`、`kdj(df, 9)`），「策略參數」區就會自動出現該指標的調參欄位（RSI 週期、MACD 快慢線…），**改值即生效**——不必自己寫 `PARAM_DEFS`，也不必改寫呼叫方式。自己寫的 `PARAM_DEFS` 優先。
- 訊號於**K 線收盤**產生，於**下一根開盤**成交（避免未來函數）。

### 3.1 PARAM_DEFS（自動生成參數輸入）

在程式碼中定義 `PARAM_DEFS` 字典，介面會自動在「策略參數」區生成對應輸入：

| 欄位 | 說明 |
|------|------|
| `label` | 顯示名稱 |
| `type` | `int` / `float` / `choice` |
| `min` / `max` | 數值範圍 |
| `default` | 預設值 |
| `step` | 每次調整幅度 |
| `choices` | 當 `type = "choice"` 時的選項清單 |

### 3.2 策略旗標（由程式碼宣告）

在策略碼最上方宣告，Quant Studio 會**自動偵測並套用**（不需 UI 開關）：

| 旗標 | 說明 |
|------|------|
| `USE_VOL_TARGET = True` | 啟用波動目標（倉位公式，抗震盪） |
| `VOL_TARGET = 0.6` | 年化目標波動（0.6＝60%）；未寫預設 0.6 |
| `USE_HEDGE = True` | 用「網格鎖倉引擎」執行（自動加單／鎖倉／解鎖） |
| `USE_TRAILING_STOP` / `TRAIL_PCT = 0.08` | 移動停損：自進場後高點回檔 8% 出場 |
| `USE_ATR_STOP` / `ATR_STOP_MULT = 2.5` / `ATR_STOP_N = 14` | ATR 波動停損（進場價 ∓ 倍數×ATR） |
| `MAX_HOLD_BARS = 40` | 最長持倉根數，超過即出場（時間出場） |
| `MAX_DRAWDOWN_STOP = 0.35` | 權益自高點回撤達此比例即全部平倉並停手 |
| `TARGET_LEVERAGE = 1.5` | 目標槓桿（直接設定槓桿倍數） |
| `WEIGHT_MODE = "risk_parity"` | 多資產風險平價（各資產以波動倒數配權） |

偵測到時，程式碼編輯器下方會顯示「策略宣告：波動目標 60%」等提示。

```python
USE_VOL_TARGET = True
VOL_TARGET = 0.6
```

## 4. 引擎（自動路由）

| 引擎 | 觸發條件 | 特性 |
|------|----------|------|
| 做多引擎 | 訊號皆 ≥ 0 | 只做多、可支援止損/止盈 |
| 多空反手引擎 | 訊號含 -1 | 依訊號翻倉（-1/0/1），**不支援止損/止盈** |
| 網格鎖倉引擎 | 勾選「送入網格鎖倉引擎」 | 把你的訊號當**趨勢進場訊號**，自動加單 / 鎖倉 / 解鎖 |

勾選「送入網格鎖倉引擎」時，你的程式碼本身不需要寫鎖倉，引擎會自動處理。

## 5. 回測設定與成本模型

| 設定 | 說明 |
|------|------|
| 初始資金 | 回測起始權益（USDT） |
| 基礎倉位 | 每次投入佔當前權益比例（動態倉位時為基礎倉位） |
| 手續費率 | 每筆成交單邊收取（預設 0.1%） |
| 滑點 | 成交價的不利偏移（預設 0.05%） |
| 槓桿 | 名義曝險倍數 |
| 波動目標 | 勾「啟用波動目標（抗震盪）」＋設定目標年化波動 (%)：倉位 = 基礎倉位 × clip(目標波動 ÷ 平滑後已實現波動, 0.2, 2.0)。**高波動自動縮倉、低波動加倉**——不砍任何交易，是「倉位公式」不是「濾網」。（預設關；參考值 60%） |
| 止損 / 止盈 | **僅做多引擎支援**；同根 K 線同時觸發時以止損優先 |
| 倉位管理 | 固定 / 逆馬丁 / 馬丁 |

### 5.1 倉位管理（逆馬丁 / 馬丁）

訊號不變，只調整**每筆交易的倉位大小**。每筆結束後以「最近交易盈虧的加權平均」決定下一筆倍率：

- **逆馬丁**：連勝加倉、連虧縮倉。
- **馬丁**：連虧加倉。
- 可設定加/減倉倍率、倍率上下限、取樣筆數、遠近衰減、單筆倉位上下限。

> 注意：若「基礎倉位 = 100%」且「單筆上限 = 100%」，加碼會被上限吃掉（加不上去）。要留加碼空間，請把基礎倉位降到 0.5 左右。

## 6. 多籌組合回測

切到「多籌組合」模式：

- 以**彈性勾選**多選標的（建議 ≥ 3），共用週期與日期。
- **多標的權重**留空＝等權；或輸入逗號分隔權重（對應資產順序，例如 `0.5, 0.3, 0.2`）。
- 每個標的分配 `初始資金 × 權重`，各自獨立回測後把權益**相加**成組合權益。
- 輸出：組合績效、**權益曲線（起點 = 100 可比較）**、各資產績效表、合併交易明細。

> 這是**等權／加權組合**（分散），**不是**跨幣對沖、配對交易或自動選幣。

---

## 7. 未來函數（look-ahead）檢測

回測後會自動做**截斷測試**：用 `df[:t]` 重算 `signal[t]`，與全樣本結果比對；不一致代表有未來函數。

- 常見原因：`shift(-n)`、`rolling(center=True)`、或用到**整段**的 `mean / std / z-score`。
- 多幣模式下以第一個選取的資產抽樣（該檢查是程式碼性質，與幣種無關）。

## 8. 讀數區：圖表與指標怎麼看

### 8.1 績效指標

| 指標 | 意義 |
|------|------|
| 總收益率 | 期末權益 ÷ 期初 − 1 |
| 年化 | 幾何年化報酬（CAGR）|
| 夏普比率 | 報酬 ÷ 波動（越高越好） |
| 卡瑪比率 | 年化 ÷ 最大回撤 |
| 最大回撤 | 由高點回落的最大幅度（負值） |
| 勝率 | 獲利交易 ÷ 總交易數 |
| 交易次數 | 已平倉交易數 |
| 買入持有 | 同期間單純持有的報酬（基準） |
| 超額報酬 | 策略報酬 − 買入持有 |

### 8.2 圖表

- **權益曲線**：策略權益 vs 買入持有（鎖倉時另加「直接停損」對照）。多幣模式所有線以起點 = 100 標準化，方便比較。可切「線性 / 對數」座標、可「釘選目前」多條結果疊圖比較、並顯示上一次回測的幽靈曲線。
- **回撤**：權益相對歷史高點的百分比回落。
- **價格與買賣點**：K 線圖（超過 500 根時自動改用收盤線，避免過密）+ 買入 ▲ / 賣出 ▼ 標記。可切「自動 / K線 / 收盤線」。
- **滾動指標**：以滾動視窗（30 / 90 / 180 根）計滾動夏普與年化波動，看策略在不同時期的穩定度（regime）。
- **成本拖累**：毛權益（無成本）vs 淨權益，並標示總成本與其中手續費——看成本吃掉多少報酬。
- **曝險**：持倉時間比例（0/1 面積圖）與平均持倉時間。
- **交易明細**：每筆交易的進出時間、價位、數量、成本、收入、盈虧、收益率、原因（多幣模式帶「資產」欄）。

> 以上三張分析圖（滾動指標 / 成本拖累 / 曝險）**單幣模式**才顯示（多幣組合無逐 bar 費用與曝險）。

> 誠實提醒：評級高、回測漂亮 ≠ 未來會賺。請注意是否打敗買入持有、成本是否吃掉報酬、是否只在少數資產有效。

## 10. 常見問題

| 症狀 | 可能原因 |
|------|----------|
| 編譯失敗 | 語法錯誤，編輯器下方會顯示訊息與行號 |
| 策略執行失敗 | `generate` 未定義、回傳長度不符、或執行時例外（會顯示 traceback） |
| 結果打不贏買入持有 | 訊號太弱、換手過高、成本 ≥ 報酬，或樣本外失效 |
| 多空引擎沒有止損 | 多空（反手）引擎不支援止損/止盈，需在程式碼內自行處理 |
| 找不到資料 | 本地 CSV 需存在對應檔；或改用 Binance API 來源 |

## 11. 策略程式碼範例集（怎麼寫策略）

這一節給「想自己寫策略」的人：先複習契約與工具，再給一整組可直接貼上的範例。

### 11.1 契約（30 秒複習）

- 定義 `generate(df, params)`（或 `generate(df)`），回傳**目標倉位序列**，長度＝K 線數。
- 值：`1` 做多、`0` 空倉、`-1` 做空（含 `-1` 會自動切到多空引擎）。
- `df` 欄位：`open / high / low / close / volume`，索引為時間（DatetimeIndex）。
- 訊號於**收盤**產生、**下一根開盤**成交（引擎自動位移，**不要**自己寫 `shift(-1)`）。

### 11.3 範例 1：雙 EMA 趨勢（多空反手）

```python
import pandas as pd, numpy as np
PARAM_DEFS = {
    "fast": {"label": "快線", "type": "int", "min": 2, "max": 200, "default": 20, "step": 1},
    "slow": {"label": "慢線", "type": "int", "min": 5, "max": 400, "default": 60, "step": 1},
}
def generate(df, params):
    f = ema(df["close"], params["fast"])
    s = ema(df["close"], params["slow"])
    return np.where(f > s, 1, -1)      # 多空反手
```

> 只要做多就改成 `return (f > s).astype(int)`。

### 11.4 範例 2：RSI 反轉（進場後持有到反向訊號）

```python
def generate(df, params):
    r = rsi(df["close"], params["n"])
    sig = pd.Series(0, index=df.index)
    sig[r < params["low"]] = 1         # 超賣做多
    sig[r > params["high"]] = -1       # 超買做空
    return sig.ffill().fillna(0)       # 進出之間維持持倉
```

### 11.5 範例 3：布林帶均值回歸

```python
def generate(df, params):
    b = bollinger(df["close"], params["n"], params["k"])
    sig = pd.Series(0, index=df.index)
    sig[df["close"] < b["lower"]] = 1
    sig[df["close"] > b["upper"]] = -1
    return sig
```

### 11.6 範例 4：MACD 動能（只做多）

```python
def generate(df, params):
    m = macd(df["close"], 12, 26, 9)
    return np.where(m["macd"] > m["signal"], 1, 0)
```

### 11.7 範例 5：通道突破（Donchian）

```python
def generate(df, params):
    n = params["n"]
    hi = df["high"].rolling(n).max().shift(1)   # 前 n 根高點（不含當根）
    lo = df["low"].rolling(n).min().shift(1)
    sig = pd.Series(0, index=df.index)
    sig[df["close"] > hi] = 1
    sig[df["close"] < lo] = -1
    return sig.ffill().fillna(0)
```

### 11.8 範例 6：趨勢濾網 + 進場（只在多頭做多）

```python
def generate(df, params):
    trend = ema(df["close"], params["trend_n"])                         # 大方向
    entry = df["close"] > df["close"].rolling(params["n"]).mean()       # 進場條件
    return (entry & (df["close"] > trend)).astype(int)
```

### 11.9 範例 7：多空 + 波動目標（由程式碼宣告）

```python
USE_VOL_TARGET = True
VOL_TARGET = 0.6

def generate(df, params):
    f = ema(df["close"], 50)
    s = ema(df["close"], 200)
    return np.where(f > s, 1, -1)
```

> 回傳含 `-1` 會走多空引擎；`USE_VOL_TARGET` 讓引擎以波動目標調整倉位（通常可降回撤、提升 Sharpe）。

### 11.10 範例 8：加條件（成交量 / 波動濾網）

```python
def generate(df, params):
    base = (ema(df["close"], 20) > ema(df["close"], 60)).astype(int)
    vol_ok = df["volume"] > df["volume"].rolling(20).mean()   # 量能放大才進
    calm = df["close"].pct_change().rolling(20).std() < params["vol_max"]
    return (base & vol_ok & calm).astype(int)
```

### 11.11 寫策略的紀律（很重要）

- **因果**：只能用「當根與之前」的資料。用到整段 `mean/std/zscore`、`rolling(center=True)`、`shift(-n)` 都會被回測的 **look-ahead 檢測**抓出來。
- **別自己位移**：訊號代表「收盤當下的目標倉位」，下一根開盤才成交。
- **長度要對**：回傳長度＝`len(df)`；用 `pd.Series(..., index=df.index)` 最保險。
- **暖機 NaN**：前 n 根請自行 `fillna(0)` 或 `where`，避免整段被當 0。
- **效能**：盡量向量化，避免 `for i in range(len(df))` 逐根；需要狀態機（如範例 7）才用迴圈。
- **參數**：數值參數放進 `PARAM_DEFS`，介面自動生成輸入/滑桿，也方便日後優化。

### 11.12 症狀 → 寫法 對照

| 你想要的 | 寫法 |
|----------|------|
| 只做多 | 回傳 0/1（`.astype(int)`） |
| 多空反手 | 回傳 +1/−1（`np.where(cond, 1, -1)`） |
| 進場後持有到出場 | `sig.ffill()` 讓訊號延續 |
| 只在多頭做多 | 加 `df["close"] > ema(df["close"], 200)` 濾網 |
| 突破前高才買 | `df["high"].rolling(n).max().shift(1)` |
| 波動太大不進場 | `df["close"].pct_change().rolling(n).std() < 門檻` |
| 用參數控制 | `PARAM_DEFS` + `params["key"]` |

### 11.13 除錯

- **編譯/執行錯誤**：編輯器下方提示，或結果區紅框顯示 traceback。
- **「沒有完成的交易」**：可能訊號一直同號（沒換手）或全部是 0。
- **績效怪異**：先看 look-ahead 檢查與「買入持有」對照，再看換手率與成本。

## 12. 參數優化（網格 + 熱力圖 + 過擬合檢測）

在結果區的「參數優化」分頁：

1. **優化指標**：夏普 / 總收益 / 卡瑪 / 年化 / 盈虧比 / 最大回撤。
2. **樣本外驗證**：可選「70% 訓練 / 30% 驗證」（或 80/20、60/40）。開啟後會用**前段訓練**找最佳、再用**後段驗證**，用來檢查是否過擬合。
3. **勾選 1–2 個參數** 並設定 最小 / 最大 / 步長；未勾的用目前「策略參數」值。
4. **開始優化** → 逐一回測所有組合（組合數上限 400）。

輸出：
- **過擬合提醒框**：說明優化是「事後最佳化」；開啟樣本外驗證時，會顯示訓練／驗證區間、**樣本內最佳那組的「訓練 → 驗證」指標**，並在「樣本外最佳」與「樣本內最佳」不同時提出警告。
- **圖表**：2 個參數＝熱力圖、1 個＝折線圖；可用 **樣本內 / 樣本外** 切換顯示哪一段的指標（OOS 熱力圖若雜亂無章＝過擬合）。
- **明細表**：各組參數的訓練指標、所選指標的「驗證」值，以及 **鄰域均值**（相鄰參數格的平均；越接近該格代表越穩健、越像高原）。

> 重點：找**穩定的高原**（附近參數都不差），而不是單一尖峰——尖峰通常是過擬合，換時段就崩。
> **誠實說明**：過擬合沒有萬靈丹。樣本外驗證與鄰域均值是實用且標準的輔助，但仍無法保證未來有效；請搭配不同市場／時段與常識判斷。
